В ботаническом саду посадили семя чихотной травы. Растёт она по строгому правилу: каждый побег первую неделю жизни
набирает силу, а потом каждую неделю выпускает по одному новому побегу. Через неделю после посадки показался первый
побег, через две он всё ещё был один, через три побегов стало два, через четыре — три, через пять — пять. Садовник
ведёт учёт в 32-битном счётчике: когда число побегов перестаёт в него помещаться, старшие биты просто теряются.

Число побегов через `n` недель — это число Фибоначчи `F(n)`:

```
F(0) = 0, F(1) = 1, F(n) = F(n - 1) + F(n - 2)
```

Дан массив `A` из `N` целых чисел. Для каждого найдите, что покажет счётчик через `A[i]` недель после посадки:

```
C[i] = F(A[i]) mod 2^32
```

Задачу можно сдать на видеокарте (`gpu-cuda`), на её симуляторе (`cuda-sim`), на векторном процессоре RISC-V
(`riscv-rvv`) и на ядре Coral NPU (`coral-npu`).

Реализуйте функцию

```cpp
void solve(const uint32_t* A, uint32_t* C, int N);
```

`A` и `C` лежат в памяти GPU. `solve` выполняется на CPU: она запускает ядра и возвращается, проверяющая система
сама дожидается их завершения. Складывать неделю за неделей слишком долго на любом процессоре: `A[i]` доходит
до миллиарда. Но из пары соседних чисел `F(k)` и `F(k + 1)` можно сразу получить пару `F(2k)` и `F(2k + 1)`, и тогда
до миллиардной недели — около тридцати шагов.

## На симуляторе GPU (`cuda-sim`)

Та же `solve` на CUDA исполняется в GPGPU-Sim на модели NVIDIA Quadro V100 (QV100). Score — число тактов
симулируемой видеокарты: чем меньше, тем лучше. `cudaMemcpy*` и обмен между потоками варпа (`__shfl_*_sync`)
в решении запрещены.

## На RISC-V (`riscv-rvv`)

Та же `solve` на C, C++ или ассемблере RISC-V для RV64GCV с векторами по 256 бит; массивы лежат в обычной памяти.
Score — число выполненных инструкций плюс 10 за каждый промах кэша L1 и 100 за каждый промах L2: чем меньше,
тем лучше.

## На Coral NPU (`coral-npu`)

Та же `solve` на C или C++ для ядра Coral NPU без операционной системы: RV32IMF с Zbb и векторами по 128 бит
(Zve32x, Zve32f), стандартной библиотеки C++ нет. У ядра 8 КБ памяти под код и 32 КБ под данные; массивы лежат
в этой памяти данных. Score — число инструкций, выполненных ядром: чем меньше, тем лучше. В C++ объявляйте `N`
как `int32_t`, как в шаблоне решения: на этой платформе `int32_t` — это `long`, и `solve` с параметром `int` будет
другой функцией. Беззнаковые 32-битные сложение и умножение сами отбрасывают старшие биты, так что 64-битные числа
здесь не нужны.

## Пример

| A | C |
| --- | --- |
| 0 1 2 3 10 47 48 1000000000 | 0 1 1 2 55 2971215073 512559680 1532868155 |

Через 10 недель на грядке 55 побегов. `F(47)` = 2 971 215 073 — последнее число Фибоначчи, которое помещается
в 32 бита. Уже `F(48)` = 4 807 526 976, и счётчик покажет 4 807 526 976 − 4 294 967 296 = 512 559 680.

## Ограничения

- 1 ≤ N ≤ 10 000 000 на видеокарте, 1 ≤ N ≤ 100 000 на `riscv-rvv` и `cuda-sim`, 1 ≤ N ≤ 3000 на `coral-npu`;
- 0 ≤ A[i] ≤ 1 000 000 000;
- ответ сравнивается точно.
