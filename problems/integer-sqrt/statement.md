На фестивале света дроны каждый вечер выстраиваются в небе в сплошной квадрат: `k` рядов по `k` дронов. Режиссёр
хочет, чтобы квадрат был как можно больше; дроны, которым не хватило места, остаются на земле. Про каждый из `N`
вечеров известно, сколько исправных дронов есть у труппы.

Дан массив `A` из `N` целых чисел: `A[i]` — число дронов в вечер `i`. Для каждого вечера найдите сторону наибольшего
квадрата, то есть наибольшее целое `k`, для которого `k * k ≤ A[i]`:

```
C[i] = floor(sqrt(A[i]))
```

Задачу можно сдать на видеокарте (`gpu-cuda`), на её симуляторе (`cuda-sim`), как схему (`rtl`), на векторном
процессоре RISC-V (`riscv-rvv`) и на ядре Coral NPU (`coral-npu`).

Реализуйте функцию

```cpp
void solve(const uint32_t* A, uint32_t* C, int N);
```

`A` и `C` лежат в памяти GPU. `solve` выполняется на CPU: она запускает ядра и возвращается, проверяющая система
сама дожидается их завершения. Ответ нужен точный, а числа занимают все 32 бита: в мантиссе `float` их только 24,
и рядом с большими точными квадратами корень в одинарной точности ошибается на единицу. Такие числа в тестах есть.

## На симуляторе GPU (`cuda-sim`)

Та же `solve` на CUDA исполняется в GPGPU-Sim на модели NVIDIA Quadro V100 (QV100). Score — число тактов
симулируемой видеокарты: чем меньше, тем лучше. `cudaMemcpy*` и обмен между потоками варпа (`__shfl_*_sync`)
в решении запрещены.

## Как схема (`rtl`)

Решение — модуль `solve` на SystemVerilog. `A` и `C` — память проверяющей системы: выставьте индекс на `A_addr`,
и на следующем такте элемент придёт на `A_data`; запись `C[C_addr] = C_data` происходит на такте, где поднят
`C_write`. Проверяющая система поднимает `start` на первый такт; поднимите `done`, когда записаны все элементы `C`.
До `start` все регистры равны нулю. Score — число тактов до `done`, умноженное на глубину логики (наибольшее число
вентилей на пути между регистрами) и на число транзисторов синтезированной схемы: чем меньше, тем лучше. Схема должна
быть синхронной: без защёлок и асинхронных сбросов. Корень можно извлекать столбиком, по одной двоичной цифре за шаг:
на это хватает сдвигов, сравнения и вычитания. Сколько таких шагов уместить в один такт, решать вам.

## На RISC-V (`riscv-rvv`)

Та же `solve` на C, C++ или ассемблере RISC-V для RV64GCV с векторами по 256 бит; массивы лежат в обычной памяти.
Score — число выполненных инструкций плюс 10 за каждый промах кэша L1 и 100 за каждый промах L2: чем меньше,
тем лучше.

## На Coral NPU (`coral-npu`)

Та же `solve` на C или C++ для ядра Coral NPU без операционной системы: RV32IMF с Zbb и векторами по 128 бит
(Zve32x, Zve32f), стандартной библиотеки C++ нет. У ядра 8 КБ памяти под код и 32 КБ под данные; массивы лежат
в этой памяти данных. Score — число инструкций, выполненных ядром: чем меньше, тем лучше. В C++ объявляйте `N`
как `int32_t`, как в шаблоне решения: на этой платформе `int32_t` — это `long`, и `solve` с параметром `int` будет
другой функцией. Вещественные числа у этого ядра только одинарной точности, а 64-битное целое занимает два регистра.

## Пример

| A | C |
| --- | --- |
| 0 1 8 9 15 16 999999 1000000 4294836224 4294836225 4294967295 | 0 1 2 3 3 4 999 1000 65534 65535 65535 |

Из 8 дронов выйдет только квадрат 2 × 2, а девятый дрон позволяет построить 3 × 3. Миллион дронов — это ровно
1000 × 1000, но стоит одному не взлететь, и сторона квадрата уже 999. Самый большой квадрат в этой задаче —
65 535 × 65 535 = 4 294 836 225 дронов: на сторону 65 536 не хватит даже 4 294 967 295 дронов.

## Ограничения

- 1 ≤ N ≤ 10 000 000 на видеокарте, 1 ≤ N ≤ 2048 на `rtl`, 1 ≤ N ≤ 100 000 на `riscv-rvv` и `cuda-sim`,
  1 ≤ N ≤ 3000 на `coral-npu`;
- 0 ≤ A[i] ≤ 4 294 967 295;
- ответ сравнивается точно.
