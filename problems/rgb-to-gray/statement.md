Переведите цветную картинку в оттенки серого: на видеокарте (`gpu-cuda`), как схему (`rtl`), на векторном процессоре
RISC-V (`riscv-rvv`) или на ядре Coral NPU (`coral-npu`).

Картинка из `N` пикселей задана тремя плоскостями байтов: `R`, `G` и `B`. Вычислите яркость каждого пикселя с целыми
весами стандарта BT.601:

```
Y[i] = (77 * R[i] + 150 * G[i] + 29 * B[i]) >> 8
```

Сумма весов равна 256, поэтому яркость — снова байт: белый остаётся равным 255.

Реализуйте функцию

```cpp
void solve(const uint8_t* R, const uint8_t* G, const uint8_t* B, uint8_t* Y, int N);
```

Плоскости лежат в памяти GPU. `solve` выполняется на CPU: она запускает ядро и возвращается, проверяющая система сама
дожидается его завершения. Любой конвейер обработки изображения с камеры делает это с каждым кадром; байты — как раз
то место, где окупаются широкие векторы и маленькие схемы.

## Как схема (`rtl`)

Решение — модуль `solve` на SystemVerilog со входом `N` и четырьмя потоками байтов. Проверяющая система поднимает
`start` на первый такт и со следующего такта подаёт по одному пикселю за такт: пока подняты `R_valid`, `G_valid`
и `B_valid`, на `R_data`, `G_data` и `B_data` лежит пиксель. Отдавайте `Y[i]` в том же порядке: поднимите `Y_valid`
и выставьте байт на `Y_data`; когда отданы все, поднимите `done`. До `start` все регистры равны нулю. Score — число
тактов до `done`, умноженное на глубину логики (наибольшее число вентилей на пути между регистрами) и на число
транзисторов синтезированной схемы: чем меньше, тем лучше. Схема должна быть синхронной: без защёлок и асинхронных
сбросов. Умножение на константу — это несколько сложений со сдвигом, а сдвиг — это провод.

## На RISC-V (`riscv-rvv`)

Та же `solve` на C, C++ или ассемблере RISC-V для RV64GCV с векторами по 256 бит; массивы лежат в обычной памяти.
Score — число выполненных инструкций плюс 10 за каждый промах кэша L1 и 100 за каждый промах L2: чем меньше, тем
лучше.

## На Coral NPU (`coral-npu`)

Та же `solve` на C или C++ для ядра Coral NPU без операционной системы: RV32IMF с Zbb и векторами по 128 бит (Zve32x,
Zve32f), стандартной библиотеки C++ нет. У ядра 8 КБ памяти под код и 32 КБ под данные; массивы лежат в этой памяти
данных. Score — число инструкций, выполненных ядром: чем меньше, тем лучше. В C++ объявляйте `N` как `int32_t`, как
в шаблоне решения: на этой платформе `int32_t` — это `long`, и `solve` с параметром `int` будет другой функцией.

## Пример

| R | G | B | Y |
| --- | --- | --- | --- |
| 255 255 0 0 10 | 255 0 255 0 20 | 255 0 0 255 30 | 255 76 149 28 18 |

Чистый красный: `77 * 255 >> 8 = 76`. Последний пиксель: `(770 + 3000 + 870) >> 8 = 4640 >> 8 = 18`.

## Ограничения

- 1 ≤ N ≤ 10 000 000 на видеокарте, 1 ≤ N ≤ 4096 на `rtl`, 1 ≤ N ≤ 100 000 на `riscv-rvv`,
  1 ≤ N ≤ 6000 на `coral-npu`;
- в плоскостях лежат любые байты;
- ответ сравнивается точно.
